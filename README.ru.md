# AI-Driven Async Trading Bot & Streamlit Analytics Dashboard

Высокопроизводительный асинхронный торговый робот на Python, сочетающий технический анализ рынка со сквозной фильтрацией фундаментального новостного шума через локальные и облачные Large Language Models (LLMs). Комплекс снабжен интерактивной веб-панелью для мониторинга эквити и логов в реальном времени.

⚠️ **Важное примечание по безопасности:** Данный репозиторий содержит исключительно архитектурный каркас (инфраструктуру), движок асинхронного сбора данных и веб-интерфейс. Продакшн-промпты ИИ, веса проприетарных моделей и точные математические формулы риск-менеджмента полностью изолированы, вынесены в приватный контур и добавлены в `.gitignore`. В публичном коде боевая стратегия заменена на демонстрационный Mock-класс.

## 🚀 Ключевые технологические фичи движка

### 1. Асинхронное ядро и отказоустойчивый парсинг
* **Asyncio & HTTPX:** Движок построен на базе неблокирующих запросов, обеспечивая параллельный сбор биржевых метрик и сквозной парсинг новостных лент.
* **Network Handling:** Внедрен обход сетевых ограничений и жестких политик редиректов веб-ресурсов (`follow_redirects=True`).
* **Парсинг битых данных:** Реализована низкоуровневая обработка исключений при чтении потоков данных, устранена проблема невидимых BOM-символов Windows через декодирование класса `utf-8-sig`.

### 2. Гибкая интеграция ИИ-агентов (Pluggable AI Layer)
* **LLM Agnostic:** Архитектура поддерживает бесшовное переключение между удаленными API (Gemini API) и локально развернутыми LLM-рантаймами через API-серверы LM Studio (модели семейства Qwen, DeepSeek).
* **Форматирование ответов:** Системные промпты спроектированы под строгое валидирование ответов моделей. Архитектура гарантирует генерацию валидного JSON на выходе из ИИ-модуля для безопасного парсинга торговых сигналов бэкендом.

### 3. Инженерный риск-менеджмент и защита капитала
* **Управление маржой:** Жесткий контроль параметров ордеров и принудительная фиксация кредитного плеча на уровне биржевого аккаунта (`Leverage 1x`).
* **Честный бэктест:** При расчете доходности движок учитывает реальные торговые уязвимости: заложена обязательная комиссия биржи (Taker Fee 0.05%) и алгоритм защиты от проскальзывания цен (Slippage) во время импульсных движений на новостях высокой важности.

### 4. Интерактивная веб-аналитика (Streamlit Frontend)
* Разработан отзывчивый UI-дашборд на фреймворке Streamlit, обеспечивающий визуализацию торговой активности без перезагрузки страницы с помощью `st_autorefresh`.
* Настроена потоковая обработка CSV-логов сделок и автоматическое построение интерактивных графиков прибыли.

## 📁 Архитектура репозитория
* `dashboard.py` — Streamlit фронтенд-панель аналитики.
* `Testnet binance vision AI/` — Рабочая зона робота.
  * `live_trader.py` — Основной движок торгового цикла и логики.
  * `ai_service.py` — Модуль интеграции с LLM и парсинга JSON-ответов.
  * `news_parser.py` — Высокоскоростной парсер новостных потоков.
  * `notifier.py` — Асинхронный модуль Telegram-нотификаций о сделках и риск-менеджменте.
